# 俱樂部首頁改版（我的俱樂部抽屜首頁）

版本 1.0（2026-11-12）。狀態：已實作、build 通過（使用者回報）、已 commit 並要求 push；**畫面測試使用者決定先跳過，不要追問**。
只改版面與樣式，不改功能、資料、權限、操作路徑。衝突時以 生成後.md 為準。

## 1. 使用者決定的方向
功能總覽 × 維持現有定位 × Lucide 線條圖示 × 桌面兩欄 × 跟隨系統深色模式。

## 2. 版面
- 個人資訊區（ClubHeader）：維持深綠 #34463c，不改。
- 集點福利卡（ClubPointsCard）：inline style 改成 CSS class（`ch-pts` 系列）；資訊、「去評分」按鈕與紅點、「待確認」提示、onClick、aria-label 不變。
- 我的統計＋我的評分：視覺同一區，桌面與手機都 2 欄，仍是各自獨立卡片。沒有評分入口（管理者）時統計撐滿 1 欄。
- 功能入口（留言板、我的心得、我的聚會、我的投稿、集點卡）：桌面 2 欄、手機（≤440px）1 欄；奇數張時最後一張撐滿。抽屜桌面維持 420px。
- 圖示：Lucide 線條圖示取代 emoji（chart-no-axes-column、star、notebook-pen、calendar-days、pen-line、ticket、message-square）。

## 3. 權限條件（原樣保留）
- 我的統計：所有人。
- 我的評分：`personal.isLoggedIn && !isAdmin`。
- 留言板：`isAdmin`。
- 我的投稿：`isVip && !isAdmin`。
- 集點卡入口：`!isAdmin && !isVip`。
- 集點福利卡：`personal.isLoggedIn && isVip && !isAdmin`。
- 保留：所有 `setView`／`openStats`／`setRatingsFocus(null)`／`setGatheringTarget(null)` 路徑、`role="dialog"`、`aria-label="我的俱樂部"`、點背景關閉、`useBackClose`、TodayRatingModal。

## 4. 檔案
- 修改 `src\MyList.tsx`：加 2 行 import；ClubPointsCard 改 class；首頁 JSX（從「我的桌遊（首頁）」註解到檔尾）重寫；`<aside>` 加 `club-home` class。
- 新增 `src\components\ClubIcons.tsx`：`<ClubIcon name="stats|star|notes|calendar|submit|ticket|message" size? />`。
- 新增 `src\styles\club-home.css`：由 `MyList.tsx` import，**沒有動 `App.css`**。
- 不動：`mylist.css`、`vip.css`、`club-board.css`、`.club-note`、其他抽屜、`App.css` import 順序。舊的 `club-menu-*`、`club-list` 等 CSS 沒有刪（首頁不再使用，但其他處可能還用，刪除前須全專案搜尋）。

## 5. 新 class
- 容器：`club-home`（只在首頁 `<aside>`）。
- 集點卡：`ch-pts`、`ch-pts-loading`、`ch-pts-col`、`ch-pts-label`、`ch-pts-num`、`ch-pts-sub`、`ch-pts-arrow`、`ch-pts-go`、`ch-pts-dot`、`ch-pts-warn`。
- 共用：`ch-card`、`ch-icon`、`ch-text`、`ch-sub`、`ch-count`、`ch-arrow`。
- 區塊：`ch-records`（`is-single` 為 1 欄）、`ch-record`、`ch-menu`、`ch-entry`。
- 所有選擇器以 `.mylist-drawer.club-home` 開頭（優先度高於 vip.css）。

## 6. 圖示決定
專案沒有 `lucide-react`（package.json 沒有，也不新增依賴）。`ClubIcons.tsx` 內嵌 Lucide 的 SVG 路徑（ISC 授權）。之後若安裝 lucide-react，只需改這一個檔案。

## 7. 深色模式隔離
- 只用 `@media (prefers-color-scheme: dark)`，只作用在 `.mylist-drawer.club-home`；不動 `:root`，不加手動開關。
- 顏色用 `--ch-*` 變數，定義在 `.mylist-drawer.club-home`，深色值只在媒體查詢內覆寫。
- `vip.css` 的 `:root{color-scheme:light}` 是全站設定；首頁抽屜內另設 `color-scheme: dark`（只影響此子樹的捲軸與表單元件）。
- 其他抽屜沒有 `club-home` class，不受影響。VIP 金色卡與警告紅字在深色用較亮色值。

## 8. 手機與底部導覽
≤760px 時 `vip.css` 既有規則讓抽屜停在導覽上方（`bottom: var(--nav-h)`）；首頁另加 28px 底部留白。橫向溢出靠 `minmax(0,1fr)` 與 `overflow-wrap` 避免。
